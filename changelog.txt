Mama Build Tool - changelog
Newest release first. See docs/ for the design notes behind the larger changes.

unreleased
 - feature: the load phase draws one live line per dep, with no git chatter
 - feature: one build log per run, holding both the load and the build
 - bugfix: a targeted run loads and builds only the subtree of its target
 - bugfix: a shared dependency loads once, not once per parent
 - bugfix: wipe a target that loaded as a package, instead of doing nothing
 - bugfix: a package, a listing and a skipped test each name their target
 - perf: naming a target only skims mamafiles, and stops at the first match

release: 0.13.12 (2026-Aug-05)
