Mama Build Tool - changelog
Newest release first. See docs/ for the design notes behind the larger changes.

unreleased
 - bugfix: an MSVC debug build links again: one release CRT for the whole tree
 - bugfix: `jobs=N` now caps ninja, which read the host core count in CI
 - feature: CI logs now report each stage as it starts, and never hide a dep
 - feature: a source archive waits 15s, an artifactory fetch keeps its 5s
     GnuProject.download_timeout raises the wait for one slow mirror
 - bugfix: a failed download names the reason, instead of a urllib stack trace
 - bugfix: a stopped download keeps the cached archive it was replacing
 - feature: a killed compiler names its signal, and buffered output still prints
 - feature: mama.cmake is written only for a dep that can include it
 - bugfix: Visual Studio and Xcode now offer only configurations that link
 - bugfix: an unpublish that matches nothing names the target and the count
 - bugfix: `mama <target> unpublish=...` now unpublishes that target
 - bugfix: build_host_binary finds the host tool the bootstrap child built
 - bugfix: a Windows abort no longer leaves a grandchild process running

release: 0.13.16 (2026-Aug-07)
 There is no 0.13.15. It broke build dirs by adding -x64v3 suffix.
 - feature: set_target_march pins the instruction set of a release build
     config.set_target_march('x64', 'x86-64-v3')  in the root mamafile
     the pin renames the archive, never the build dir:
       build dir  packages/mylib/linux/
       archive    mylib-ubuntu-22-gcc11.3-x64v3-release-df76b66
       papa.txt   O release linux x64 march=x86-64-v3
     x86-64 -> x64v1    armv8.2-a -> armv82a    haswell -> x64haswell
 - feature: unpublish deletes published archives, and their local copies
 - feature: version_suffix renames a package on every platform at once
 - bugfix: a target that exports nothing no longer uploads an empty archive
 - bugfix: a failed artifactory download uses the cached archive instead
 - bugfix: noart builds every git dep from source, and a pkg dep is read-only
 - bugfix: a build no longer hangs when a pipe closes on a pending read

 - feature: nothing_to_upload() skips a target that publishes no package
